Delhi Metro Journey Planner (Demo)
==================================

Files
- index.html: Standalone demo website. Open it in a modern browser.

Important limitations
- This is an educational journey-planner demo only.
- It does not reserve seats, sell tickets, process payments, create valid QR tickets, or connect to DMRC systems.
- Delhi Metro generally uses journey tickets/QR tickets rather than reserved seats.
- For actual tickets, use official DMRC ticketing information:
  https://new.delhimetrorail.com/en/ticket
  https://delhimetrorail.com/app-based-qr-ticketing

To publish
1. Extract the ZIP.
2. Upload index.html to a GitHub repository.
3. Enable GitHub Pages in the repository settings.
4. The resulting page is still only a demo. Real ticketing requires authorized integration with DMRC/approved ticketing providers and payment compliance.
